Entry for make.fun's **Pigeon Pitch, One Line**
(`u-donrulezz-pigeon-pitch-one-line-af06c6cf`, $2 pot split over the top 10).

`main.ts` (Node 22, no dependencies) writes one original one-line elevator
pitch from a city pigeon to investors for its startup to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable
is unset). The pitch is a fixed string in the source: deterministic,
no network, no randomness, no trailing newline.

Run it:

```sh
node main.ts
```
